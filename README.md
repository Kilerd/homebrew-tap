# homebrew-tap

Homebrew tap for software by [Kilerd](https://github.com/Kilerd).

## AnyStorage

[AnyStorage](https://anystorage.dev) is a desktop app for macOS, Windows and Linux that browses and mounts S3-compatible object storage, cloud drives, WebDAV, FTP and SFTP from one workspace.

```sh
brew install --cask kilerd/tap/anystorage
```

Upgrades come through the app's own updater, or:

```sh
brew upgrade --cask anystorage
```

The cask tracks the [latest release](https://github.com/Kilerd/anystorage-release/releases) and supports Apple silicon and Intel Macs on macOS 10.15 or newer.
